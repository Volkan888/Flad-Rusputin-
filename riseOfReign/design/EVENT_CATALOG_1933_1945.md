# riseOfReign — Historischer Ereigniskatalog 1933–1945

Stand: 2026-09-02 02:46 CEST

## Zweck

Dieses Dokument definiert die erste belastbare Ereignislinie für die Release-Epoche ab 1933. Die Zahlen sind **Game-Design-Basiswerte**, keine Behauptung historischer Messdaten. Historische Fakten liefern Trigger und Kontext; die Punktwerte übersetzen sie in das riseOfReign-System.

## Eventwerte

Abkürzungen:
- AUT = Autorität
- STA = Stabilität
- LEG = Legitimität
- REP = internationale Reputation
- DIP = Diplomatie
- ECO = Wirtschaft
- IND = Industrie
- MIL = militärische Bereitschaft/Einsatzfähigkeit
- RES = Forschung
- MOR = Bevölkerung/Militärmoral, je Event angegeben
- UNR = Unruhe
- INF = Informationslage

## Humanitäre Designregel

Verfolgung, Massengewalt und Genozid werden **nicht als optimierbare Bonusmechanik** behandelt. Historisch belegte Verbrechen können als Ankerereignisse auftreten und erzeugen humanitäre, gesellschaftliche, wirtschaftliche und diplomatische Schäden. Andere Spieler können Hilfe, Aufnahme, Sanktionen, Informationsgewinn oder diplomatische Reaktionen auslösen. Im Alternativmodus können Spieler solche Entwicklungen verhindern oder abschwächen.

# Ereignis-Interaktionsmatrix

Bei internationalen Ereignissen können andere Spieler abhängig von Autorität, Beziehung und Information folgende Kategorien wählen:

1. **Unterstützen** — Geld/Ressourcen/Diplomatie.
2. **Dagegenstellen** — diplomatischer Druck, Sanktionen, Gegenkoalition.
3. **Vermitteln** — DP-Kosten, mögliche REP-Gewinne.
4. **Profitieren** — Handelslücke füllen, Investitionen, Marktanteil.
5. **Humanitär reagieren** — Aufnahme, medizinische/nahrungsmittelbezogene Hilfe.
6. **Beobachten** — INF sammeln.
7. **Verdeckte politische Einflussnahme** — nur abstrahiert über Geheimdienstpunkte und Risiko.

# Folgeketten

## Beispiel: Angriffskrieg

Kriegserklärung
→ Treibstoffverbrauch
→ Handelsrisiko
→ Mobilisierung
→ Arbeitskräfte fehlen Industrie
→ Konsumgüter sinken
→ MOR/UNR reagieren
→ andere Staaten wählen Sanktionen/Bündnisse
→ Forschung verlagert sich
→ Stadt-/Regionsevents entstehen

## Beispiel: Flüchtlings-/Emigrationswelle

Verfolgung/Krieg
→ Migration steigt
→ Herkunftsland verliert Fachkräfte
→ Zielland erhält Arbeits-/Fachkräftepotential
→ kurzfristige Wohn-/Integrationskosten
→ langfristige Forschungs-/Wirtschaftseffekte

## Status

Der Katalog deckt die **zentralen Avatar- und Weltereignisse 1933–1945** als Release-Basis ab. Detailereignisse auf Stadt-, Forschungs-, Wirtschafts- und persönlicher Ebene können später datengetrieben ergänzt werden, ohne das Kernsystem zu ändern.
