═══════════════════════════════════════════════════════════════════
HISTORISCHES EVENT HINZUFÜGEN
═══════════════════════════════════════════════════════════════════

SCHRITT 1: Öffne die Funktion InitializeHistoricalEvents()
           (ca. Zeile 3030 in RiseOfTheNorthborn.cs)

SCHRITT 2: Füge ein neues Event hinzu nach diesem Muster:

historicalEvents.Add(new HistoricalEvent(
    "EINDEUTIGE_ID_1991",                    // Eindeutige ID (z.B. Jahr_Name)
    "Titel des Ereignisses",                 // Kurzer Titel
    "26. Dezember 1991",                     // GENAUES DATUM!
    1991, 12,                                // Jahr, Monat (für Sortierung)
    "POLITIK",                               // Kategorie: POLITIK, WIRTSCHAFT, KRIEG, KATASTROPHE
    @"MOSKAU, 26. DEZEMBER 1991 - HIER DIE GESCHICHTE!
    
    Schreibe 3-6 Sätze die das Ereignis beschreiben:
    - Was ist passiert?
    - Wer war beteiligt?
    - Was waren die Konsequenzen?
    - Wie hat das Volk reagiert?
    
    Beispiel:
    Die sowjetische Flagge wird zum letzten Mal eingeholt. Michail Gorbatschow 
    tritt als Präsident der UdSSR zurück. 69 Jahre nach ihrer Gründung hört 
    die Sowjetunion auf zu existieren. Das Volk ist geschockt und verwirrt - 
    niemand weiß was die Zukunft bringt. Millionen werden verarmen, aber die 
    Hoffnung auf Freiheit keimt.",
    
    p => {
        // HIER DIE AUSWIRKUNGEN AUF DEN SPIELER:
        Console.WriteLine("\n📊 AUSWIRKUNGEN:");
        
        p.Gesundheit -= 40;
        p.Geld -= 600;
        p.LoyalitätVolk -= 70;
        p.LoyalitätPartei -= 80;
        
        Console.WriteLine($"➖ Gesundheit: -40% → {p.Gesundheit}%");
        Console.WriteLine($"💰 Geld: -600 Rubel → {p.Geld}");
        Console.WriteLine($"➖ Volk: -70% → {p.LoyalitätVolk}%");
        Console.WriteLine($"➖ Partei: -80% → {p.LoyalitätPartei}%");
        
        Thread.Sleep(4000);
    }
));

WICHTIGE PUNKTE
═══════════════════════════════════════════════════════════════════

✅ GENAUES DATUM: Verwende das echte historische Datum!
✅ GESCHICHTE: 3-6 Sätze mit dramatischer Erzählung
✅ AUSWIRKUNGEN: Zeige ALLE veränderten Stats
✅ KATEGORIE: Wähle die richtige (POLITIK/WIRTSCHAFT/KRIEG/KATASTROPHE)

VERFÜGBARE PLAYER-ATTRIBUTE:
- p.Gesundheit (0-100)
- p.Geld (kann negativ sein)
- p.LoyalitätVolk (0-100)
- p.LoyalitätPartei (0-100)
- p.EinflussKGB
- p.EinflussMilitär
- p.EinflussInternational
- p.NATOBeziehung
- p.USABeziehung
- p.ChinaBeziehung
- p.Kraft, Charisma, Intelligenz

));
