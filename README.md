# 🎮 Rise of the Northborn – Flad Rusputin Saga

Ein textbasiertes Rollenspiel in C# - vom Straßenkind zum Präsidenten einer dystopischen sowjetischen Nation.

## 🚀 Schnellstart

### Windows:
```bash
compile.bat
start.bat
```

### Linux/Mac:
```bash
chmod +x compile.sh start.sh
./compile.sh
./start.sh
```

## 📋 Spielübersicht

### Lebensphasen:
1. **Kindheit (10-15)** - Überlebe auf den Straßen
2. **KGB-Phase (15-18)** - Rekrutierung durch den Geheimdienst  
3. **Jurastudium (18-25)** - Geheimdienstakademie
4. **DDR-Einsatz (25-35)** - Ost-Berlin
5. **Präsident (35+)** - Weltherrschaft

### Features:
- ✅ 150+ historische Events (1952-2025)
- ✅ Sidechick-System mit Konsequenzen
- ✅ Telefonate (Erdogan, Trump, China)
- ✅ Generationen-Spiel
- ✅ Stammbaum-System
- ✅ Mini-Game: Schiffe Versenken

## 🎮 Spielmechanik

### Attribute: Stärke, Intelligenz, Charisma, Kraft
### Ressourcen: Geld, Gesundheit
### Loyalitäten: Partei, Volk, Familie
### Einfluss: KGB, Militär, International
