  WIE ÜBERSETZUNGEN HINZUFÜGEN?
═══════════════════════════════════════════════════════════════════

1. Öffne /app/RiseOfTheNorthborn.cs
2. Suche nach "[RU]" oder "[EN]" 
3. Ersetze die Platzhalter mit echten Übersetzungen
4. Format für jedes Event:

   historicalEvents.Add(new HistoricalEvent(
       "EVENT_ID",
       "Deutscher Titel",           // ✅ FERTIG
       "Русский заголовок",         // ⏳ FEHLT - Hier einfügen
       "English Title",             // ⏳ FEHLT - Hier einfügen
       "5. März 1953",              // ✅ FERTIG
       "5 марта 1953 года",         // ⏳ FEHLT - Hier einfügen
       "March 5, 1953",             // ⏳ FEHLT - Hier einfügen
       1953, 3,                     // ✅ FERTIG
       "POLITIK",                   // ✅ FERTIG
       @"Deutsche Geschichte...",   // ✅ FERTIG
       @"Русская история...",       // ⏳ FEHLT - Hier einfügen
       @"English story...",         // ⏳ FEHLT - Hier einfügen
       p => { /* Auswirkungen */ }  // ✅ FERTIG
   ));
